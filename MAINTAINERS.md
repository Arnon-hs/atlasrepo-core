# Maintainers

## Current maintainers

- [@Arnon-hs](https://github.com/Arnon-hs), project lead and final decision maker

## Responsibilities

- review contracts, code, tests, and documentation;
- handle security reports and coordinate releases;
- preserve the open Core and hosted Platform boundary;
- document important decisions and compatibility changes;
- set sustainable expectations for community support.

The current single-maintainer structure is a bus-factor risk. Additional
maintainers should be added only after sustained contributions and demonstrated
judgment, not to make the list look larger.
