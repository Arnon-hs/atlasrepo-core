# Roadmap

## v0.1: local evidence loop

- strict portable contracts and TypeScript types;
- local filesystem store and dossier history;
- immutable workflow releases and pinned routes;
- execution/result packs and deterministic replay;
- Dify proof case and local benchmark.

## Next

- choose a private conduct-reporting contact and add a canonical code of
  conduct before inviting broad community participation;
- adapters for Atlas Engine evidence and Atlas Research evaluation artifacts;
- a migration command when a second schema version is introduced;
- broader, source-pinned public benchmark cases;
- conformance kits for alternative storage and provider adapters.

## Later

- stable 1.0 contracts based on public implementation experience;
- additional language SDKs generated or implemented from the same schemas;
- documented interoperability with hosted AtlasRepo workspaces.

Hosted authentication, billing, content entitlements, web crawling, arbitrary
execution, and deployment orchestration remain outside Core.
