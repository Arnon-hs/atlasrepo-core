# Roadmap

## v0.1: local evidence loop

- strict portable contracts and TypeScript types;
- local filesystem store and dossier history;
- immutable workflow releases and pinned routes;
- execution/result packs and deterministic replay;
- Dify proof case and local benchmark.

## v0.2: portable workflow decisions

- additive dossier v0.2 with classified claims, required constraints, access
  hints, limitations, and evidence-backed terminal states;
- portable workflow-module release v0.2 with exact prerequisites, typed ports,
  step dependencies, effect, approval, retry, recovery and limit declarations,
  readiness criteria, and
  content-addressed materials;
- exact-pinned route v0.2 with constraint coverage and readiness results;
- pure decision-pack composition for CLI, MCP, plugin, and other hosts;
- backward-compatible validation and storage of v0.1 documents;
- source-pinned Dify `conditional-pilot` example with unresolved runtime,
  security, operations, and modified-license review gates.

The v0.2 milestone does not add execution, LLM calls, network access, hosted
drafts, authentication, ACLs, entitlements, UTM tracking, private delivery, or
Course Bot to Core.

## Next

- choose a private conduct-reporting contact and add a canonical code of
  conduct before inviting broad community participation;
- adapters for Atlas Engine evidence and Atlas Research evaluation artifacts;
- explicit v0.1-to-v0.2 migration tooling without mutating source documents;
- broader, source-pinned public benchmark cases;
- conformance kits for alternative storage and provider adapters.

## Later

- stable 1.0 contracts based on public implementation experience;
- additional language SDKs generated or implemented from the same schemas;
- documented interoperability with hosted AtlasRepo workspaces.

Mutable content drafts, hosted authentication, ACLs, billing, entitlements, UTM
tracking, private material delivery, course progress, Course Bot, Scout source
acquisition, arbitrary execution, and deployment orchestration remain outside
Core.
